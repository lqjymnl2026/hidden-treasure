# 📖 隐藏的珍宝｜66卷圣经互动学习平台（第一阶段原型）

从创世记到启示录，一卷一卷学，一章一章走：
**一起读、一起问、一起讨论、一起应用。**

## 如何打开

**双击 `index.html`** 即可在浏览器中打开，无需安装任何依赖、无需联网。
（推荐使用 Chrome / Edge / Safari 等现代浏览器。）

也可以放到任意静态服务器上访问（如 `python3 -m http.server`）。

## 数据模型（为长期扩展设计）

```
Bible → Testament → Book → Chapter → Passage
       → Question → Quiz → Discussion → Application → Prayer
```

数据与视图分离，后续增加 AI 查经、小组、课程、音频视频、讲章、儿童/青少年查经等
**不需要推翻现有结构**，只需向 `js/data/` 追加新数据层。

- `js/data/bible.js`    —— 66卷元数据
- `js/data/chapters.js` —— 章节地图（旗舰书卷已手写，其余自动生成「第X章」，可逐卷补全）
- `js/data/lessons.js`  —— 精选章节的七步互动内容
- `js/data/themes.js`   —— 主题地图
- `js/data/people.js`   —— 人物地图
- `js/app.js`           —— 路由 / 渲染 / 进度逻辑（零依赖，hash 路由）
- `css/style.css`       —— 全局样式（温暖现代风格，响应式）

## 路线图（建议第二阶段）

1. 为全部66卷逐卷补全章节地图标题（共1189章）
2. 为更多章节制作精选七步课程（优先各书卷第1章与关键章节）
3. 接入真实经文文本（注意译本版权，建议引用开放译本或取得授权的译本）
4. 用户账号系统 + 云端同步进度与笔记
5. AI 查经助手（根据用户回答给出反馈）
6. 小组/教会共读、讨论区、打卡与连续学习激励机制
7. 儿童/青少年版本（简化语言与视觉）
